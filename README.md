# 📦 Sistema de Manutenção - Embrart Embalagens

> Sistema REAL desenvolvido e em uso no chão de fábrica da Embrart - CIC Curitiba, para substituir controle de manutenção em papel.

### 🧠 O Problema que Resolvi
Na fábrica, as quebras de máquina eram anotadas em papel e se perdiam. Criei um sistema digital para controle completo.

### ⚙️ Funcionalidades
- ✅ Cadastro de requisições de manutenção
- 🔄 Controle de Status: Aberta / Em Andamento / Fechada
- 📊 Dashboard com contadores
- 🔒 Exclusão segura com senha de administrador
- ☑️ Seleção múltipla de requisições

### 💻 Tecnologias Usadas
- C# - Windows Forms
- SQL Server
- .NET Framework
- Lógica de Programação
